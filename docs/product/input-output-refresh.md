# 输入区、输出区与刷新取数

## 为什么要区分输入区和输出区

金融终端用户在 Excel 中通常会把“参数”和“结果”混在一起，例如左边写指标名，上面写年份，中间区域填结果。为了让 AI 和系统稳定理解表格，需要显式区分：

- 输入区：用户可编辑的参数。
- 输出区：系统根据参数和隐藏配置生成的结果。

这个区分能解决三个问题：

1. AI 知道哪里可以改，哪里不应该随便改。
2. 刷新引擎知道哪些单元格需要重新取数。
3. 导出和审计时能解释数据来源和生成规则。

## 当前区域定义

| 区域 | 坐标 | 用户是否可编辑 | 作用 |
|---|---|---:|---|
| 指标输入区 | `A2:A13` | 是 | 输入或绑定指标 |
| 年份输入区 | `B1:H1` | 是 | 输入年份参数 |
| 输出区 | `B2:H13` | 否，默认由刷新生成 | 显示数值或状态 |

`A13` 和 `B13:H13` 用于演示新增指标，例如“生猪价格”。

## 输入区交互

### 指标输入

用户点击 `A2:A13` 中的指标单元格时，系统显示类似 BBG W 功能的候选面板。

候选面板应包含：

- 指标名称。
- 指标分类。
- 单位。
- 数据源。
- 口径说明。

示例候选：

```text
生猪价格：全国均价（元/公斤）
生猪价格：外三元（元/公斤）
22省市生猪平均价（元/公斤）
```

用户选择候选后，系统写入指标绑定，而不是只写一个文本。

### 年份输入

用户编辑 `B1:H1` 时，只改变参数，不立即取数。

例如：

1. 用户把 `H1` 改成 `2026`。
2. 系统将 `H2:H13` 标记为 `待刷新`。
3. 用户点击 Ribbon 的“刷新”。
4. 系统根据隐藏配置拉取结果。

## 输出区状态

输出区只显示值或状态，不显示公式，不显示 `fx`。

当前支持的状态：

| 状态 | 展示 | 含义 |
|---|---|---|
| `empty` | 空白 | 没有足够配置或参数 |
| `pendingRefresh` | 待刷新 | 参数或指标已变更，需要刷新 |
| `loading` | 刷新中 | 正在取数 |
| `ready` | 数值 | 已刷新完成 |
| `failed` | 失败 | 取数失败，需要重试或检查口径 |

## 隐藏取数配置

输出区背后仍然需要保留配置。用户默认看不到，但系统在刷新、审计、导出时会使用。

一条输出配置可以理解为：

```text
目标单元格：H13
指标单元格：A13
年份单元格：H1
指标代码：CN.HOG.PRICE.NATIONAL
年份：2026
状态：pendingRefresh
最新值：空
最后刷新时间：空
```

这个设计的好处是：用户界面干净，但数据来源仍然可追踪。

## 刷新规则

点击“刷新”后，系统批量处理所有 `pendingRefresh` 的输出单元格。

刷新流程：

1. 找出状态为 `pendingRefresh` 的单元格。
2. 将状态改为 `loading`。
3. 根据指标代码和年份参数调用取数函数。
4. 成功后写入数值，并将状态改为 `ready`。
5. 失败后将状态改为 `failed`。

当前原型使用前端 mock 数据，后续接真实 DM 数据 API 时，刷新流程保持不变，只替换取数函数。

## 审计与导出

用户在输出区看不到公式，但可以通过：

- 公式审计。
- 导出表格。
- 刷新记录。

查看隐藏配置和数据链路。

导出表格时，应导出两部分：

1. 用户可见的表格结果。
2. 隐藏取数配置，用于本地 Excel 插件或后续系统继续刷新。
