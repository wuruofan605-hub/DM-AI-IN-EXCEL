# 模板广场

## 产品目标

模板广场用于沉淀可复用的表格结构。金融终端用户经常重复搭建类似的分析表，例如宏观指标时间序列、公司财务指标对比、债券估值监控。模板能力可以让用户少搭框架，把精力放在指标选择和分析判断上。

## 入口

当前入口位于左侧工作台顶部：

```text
模板广场
```

点击后打开中间弹窗，而不是在右侧 DM AI 面板里展开。原因是模板属于“选择工作框架”的动作，占用中间弹窗更适合浏览和比较。

## 弹窗结构

模板广场弹窗包含两列：

1. 默认模板。
2. 我的模板。

### 默认模板

系统预置模板，用于帮助用户快速开始。

当前示例：

- 宏观指标时间序列。
- 公司财务指标对比。
- 债券估值监控。

默认模板应展示：

- 模板名称。
- 模板说明。
- 输入区范围。
- 输出区范围。

### 我的模板

用户通过“保存为模板”创建的自定义模板。

如果没有自定义模板，应显示空状态提示：

```text
还没有自定义模板。点击 Ribbon 的“保存为模板”后会出现在这里。
```

## 保存为模板

Ribbon 中提供“保存为模板”入口。

点击后，右侧 DM AI 面板弹出保存卡片，展示：

- 模板名称。
- 输入区，例如 `A2:A13 / B1:H1`。
- 输出区，例如 `B2:H13`。
- 刷新配置摘要。
- 格式预设。

用户确认后，新模板进入“我的模板”。

## 模板保存什么

第一版模板保存的是“分析框架”，不是数据快照。

应保存：

- 输入区结构。
- 输出区范围。
- 指标绑定。
- 隐藏取数配置。
- 刷新规则。
- 展示格式。

不保存：

- 当前真实数据快照。
- 用户本地临时文件。
- 登录态或权限信息。
- API 密钥。

## 为什么不保存真实数据

金融数据有时效性、权限和来源要求。模板如果保存真实数据，用户可能误以为它是最新结果。第一版更适合保存“怎么取数”，而不是“取到过什么数”。

如果后续需要保存带数据的版本，应单独设计：

- 保存副本。
- 另存为文件。
- 导出 xlsx。
- 快照版本管理。

不要把这些能力混进模板保存。
