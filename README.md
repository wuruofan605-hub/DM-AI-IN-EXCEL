## 项目定位

本项目是 `DM AI for Excel` 的前端原型，目标是做一个类似 Bloomberg Terminal 体验的金融终端能力，但入口放在 Excel 风格的表格界面里。

当前产品方向可以理解为：用户在 Excel 中选中某个单元格或输入指标需求，例如“生猪价格”“营业收入”“毛利率”，AI 帮用户识别指标、绑定数据口径，并把对应年份的数据填入表格输出区。

这个项目目前更像产品交互 Demo，用来验证“AI + Excel + 金融/行业数据”的工作流，而不是已经接入真实数据源的生产系统。


## 当前技术栈

- 前端框架：React
- 开发语言：TypeScript
- 构建工具：Vite
- 图标库：lucide-react
- 本地开发地址通常是：`http://localhost:5173/`

常用命令：

- `npm run dev`：启动本地开发服务
- `npm run build`：做 TypeScript 检查并构建生产版本
- `npm run preview`：预览构建后的版本

## 核心文件

- `src/App.tsx`：主界面和主要交互逻辑，包括表格、AI 面板、确认卡片、模板弹窗、右键菜单等。
- `src/mockData.ts`：模拟数据，包括工作簿信息、Sheet 信息、基础表格数据、指标定义、默认模板、模拟刷新结果。
- `src/types.ts`：核心数据结构定义，例如指标、指标绑定、输出单元格配置、AI 请求上下文、聊天消息、模板草稿等。
- `src/styles.css`：整体 UI 样式，控制 Excel 风格网格、侧边栏、顶部工具栏、AI 面板、弹窗等视觉表现。
- `src/main.tsx`：React 应用入口。
- `index.html`：页面 HTML 入口，当前标题是 `DM AI for Excel`。

## 当前产品能力

当前原型已经具备这些交互能力：

- Excel-like 网格界面：展示年份、指标行、输出区域，并支持单元格选择。
- 指标识别与绑定：用户输入指标名称后，系统从模拟指标库里找候选项，并通过确认卡片让用户确认。
- AI 查询面板：支持输入自然语言需求，并附带当前工作簿、Sheet、选区和引用上下文。
- 输出刷新模拟：根据已绑定的指标和年份，模拟生成输出单元格数据，并展示刷新状态。
- 模板能力：可以基于当前输入区、输出区和刷新规则保存自定义模板。
- 右键菜单动作：提供与选区相关的快捷操作入口。
- 公式/审计面板：围绕输出单元格展示类似公式或数据口径说明的辅助信息。

## 重要现状

请注意：当前项目里的数据和 AI 行为都是前端模拟。

目前还没有：

- 真实金融数据 API
- 后端服务
- 数据库或持久化存储
- 登录、权限、机构账号体系
- 真实 Excel 插件桥接
- 真实大模型接口
- 真实 Bloomberg / Wind / FactSet 等终端数据连接

因此，后续开发时不要把 mock 行为描述成真实生产能力。如果要新增真实数据能力，应先设计数据源、指标口径、权限、刷新规则和错误处理。

## 后续协作规则

继续开发时，请遵守以下偏好：

- 用中文沟通，优先使用产品经理能理解的表达。
- 解释代码时先讲产品逻辑，再讲技术实现。
- 保留当前“金融终端 + Excel 工作流 + AI 助手”的产品方向。
- 不要轻易把页面改成普通营销页或泛 AI 聊天页。
- UI 应保持工作台/终端工具感，重点服务高频数据分析，而不是大面积装饰视觉。
- 修改代码前先理解现有 `App.tsx`、`mockData.ts`、`types.ts` 的关系。
- 改动后如涉及代码，优先运行 `npm run build` 验证。
- 如果只是改文档，不需要跑前端行为测试。

## 下一步可能方向

后续可以围绕以下方向继续推进：

- 把 mock 指标库扩展成更完整的金融和行业指标体系。
- 设计真实数据接口的返回结构和错误状态。
- 增加指标消歧体验，例如同名指标、不同数据源、不同频率、不同单位。
- 强化模板能力，让用户能保存、复用、编辑一套行业模型取数逻辑。
- 设计 Excel 插件形态下的权限、刷新、审计和数据溯源体验。
- 将 AI 面板从“简单问答”升级为“理解选区、生成公式、解释口径、批量填充数据”的分析助手。
